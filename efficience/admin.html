Administration

Le pharmacien clinicien au service de l’efficience

Tout est calculé et chiffré dans ce navigateur. Les fichiers Excel ne quittent pas votre poste ; seules les données chiffrées sont publiées.

1. Référentiels

Listes à jour de l’exercice : médicaments hors GHS, DMS LPPR, correspondance code UF → nom du service (2 colonnes : code, libellé).

2. Services et regroupements d’UF

Un service = un tableau de bord et un mot de passe. Une ligne par regroupement : 1751e = 1751, 1753, 1754, 1755 ; une UF seule s’écrit 1482 = 1482.

3. Consommations

Déposez les extractions « Analyse_conso » (un fichier par UF, plusieurs à la fois). Une UF déposée remplace ses données précédentes.

4. Vue d’ensemble et aperçu

5. Publication

Chaque service est chiffré avec son mot de passe, puis publié sur GitHub. Votre configuration (référentiels, services, mots de passe, consommations) est enregistrée chiffrée avec le mot de passe administrateur.

Le jeton n’est jamais enregistré : il est à ressaisir à chaque publication.
